# 实验环境与配置（对应论文 §6 Configurations）

## 配置

在实验中，我们使用 DeepSeek-V4-Flash-0731 作为默认的大语言模型，通过
OpenAI 兼容端点（`https://llmapi.isrc.ac.cn/v1`）访问，设置温度 \( = 0 \)
以减少随机性并提高各次运行之间的一致性，超时 120 秒、最多重试 5 次，
所有其他参数保持默认值。对于规范生成中的相关实体发现，我们根据官方
Linux 内核文档构建数据库。对于每个索引条目，我们提取其相关描述，从而
得到一个包含 14709 个实体-描述对的数据库，其中包括 11509 个函数 (78.2%)、
1588 个结构体 (10.8%)、1126 个宏 (7.7%)、314 个枚举 (2.1%) 和 172 个
类型定义/其他 (1.2%)；嵌入向量库含 14126 个有效条目。我们使用
BAAI/bge-large-en-v1.5 作为嵌入模型，相似度阈值设为 0.15（通过轻量级
调优选择，以平衡本地嵌入分数分布下的召回率和精确率）。同时，我们将
检索大小设置为 100（Top-k = 100），以使实体集便于处理。嵌入模型通过
本地 sentence-transformers 或 SiliconFlow API 访问（两者向量一致性
cosine=1.0 已验证）。在生成新规范时，为每个候选实体向大语言模型提供
最多 5 个随机选择的使用示例。不同使用示例中的约束变体在语义上是等效的，
并在检测过程中通过语义推理进行处理。在漏洞检测的报告修剪阶段，我们
允许大语言模型最多请求 5 次额外的上下文。

## 机器

所有实验均在一台配备 12 代英特尔酷睿 i7-12700H 处理器（10 核 20 线程
@ 2.30GHz）、7.6GB 内存和 251GB 存储（140GB 可用）的 Ubuntu 机器上进行。
大语言模型和嵌入模型请求通过公共网络访问。Linux 内核源码为 v6.17-rc3
快照（tarball + git 浅历史），代码 AST 索引自建（59.8 万函数、440 万
调用点），文档向量库为 numpy 自实现（替代 Chroma）。

## 与论文配置的差异对照

| 配置项 | 论文 | 本复现 |
|--------|------|--------|
| 默认 LLM | Claude Sonnet 4 (20250514) | DeepSeek-V4-Flash-0731 |
| 温度 | 0 | 0 |
| 文档库 | 14710 实体对 | 14709 实体对（11509 函数 78.2%） |
| 嵌入模型 | BAAI/bge-large-en-v1.5 (SiliconFlow API) | 同款模型（本地/API 双后端，向量一致性已验证） |
| 相似度阈值 | 0.35 | 0.15（本地嵌入分数分布差异，调优确定） |
| Top-k | 100 | 100 |
| 使用示例数 | 最多 5 个 | 最多 5 个 |
| 修剪上下文请求 | 最多 5 次 | 最多 5 次 |
| AST 搜索 | Weggli | tree-sitter 自建索引（语义等价） |
| 向量库 | Chroma + LangChain | numpy 自实现（L2 on 归一化，score=1-distance） |
| 机器 | Xeon Gold 5218, 211GB 内存, 17TB 存储 | i7-12700H, 7.6GB 内存, 251GB 存储 |
